Трансформеры (Transformers) полностью изменили ландшафт машинного обучения. С момента выхода статьи *"Attention Is All You Need"* в 2017 году, эта архитектура стала стандартом де-факто для задач NLP, а теперь активно захватывает Computer Vision и анализ временных рядов.

## Почему не RNN/LSTM?

Раньше для обработки последовательностей (текста) использовали рекуррентные нейросети. Их главная проблема — **последовательность вычислений**. Чтобы понять слово на 10-й позиции, нужно вычислить скрытые состояния для первых 9. Это медленно и плохо параллелится на современных GPU.

## Магия Self-Attention

Трансформеры решают эту проблему гениально просто: механизм *Self-Attention* позволяет сети смотреть на **все** слова в предложении одновременно и оценивать их важность друг для друга.

Формула внимания выглядит так:

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

Где:
* **Q (Query)** — запрос (что мы ищем)
* **K (Key)** — ключ (с чем мы сравниваем)
* **V (Value)** — значение (что мы берем, если ключ подошел)

### Пример на Python

Вот как это выглядит в виде простейшего псевдокода на PyTorch:

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(q, k, v):
    d_k = q.size()[-1]
    # Умножаем запросы на ключи
    scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(d_k)
    # Получаем веса внимания
    attention_weights = F.softmax(scores, dim=-1)
    # Применяем веса к значениям
    output = torch.matmul(attention_weights, v)
    return output, attention_weights
```

How quickly we transitioned from programming to metaprogramming, and from there to metaprompting. I don't know if these are established terms or not, but they just popped into my head naturally.

Metaprogramming is clear enough. That's vibe coding.

And **metaprompting** is:
- when you build an agentic system where you don't even need to write code at all: just prompts, plus configuring the wiring: MCP / skills / plugins
- you don't even write the prompts for your system yourself
- instead, you write prompts for an agent (Claude Code), which in turn writes the prompts for your agent

This is what programming has boiled down to. Not only do you not need to write code, but you can also write a prompt like "uhhh, make me this thing that does..." and a smart system expands it into a neat skill that works fairly well, if not great.

And by the way, you can lengthen this pipeline even further. That turns into **meta-metaprompting**. Well, you get the idea.

In short, programming: Press F.

Рассказываю про новости в мире AI/ML за последнюю неделю.

### Слив кода ClaudeCode

Разработчик Anthropic при публикации npm-пакета случайно залил файл, из которого легко удалось восстановить все исходники – 1906 файлов TypeScript и примерно 500к строк. Слитый код вызвал огромный ажиотаж, а энтузиасты за пару дней сделали на основе него OpenSource решения – например, [OpenCode](http://github.com/Gitlawb/openclaude) и [ClawCode](https://t.me/machinelearning_interview/2666).

Anthropic всячески пытается затереть следы слива, например, требуют блокировки репозиториев на GitHub.

### Cursor 3

Cursor 3 окончательно отходит от парадигмы AI-IDE к парадигме AgentFirst. Переработали Agents Window – теперь можно запускать множество агентов параллельно в одном интерфейсе. При этом редактор кода также остается, так что можно изменять код вручную.

### AutoClaw

[Z.ai](https://z.ai) представили AutoClaw – инструмент для быстрого и упрощенного запуска OpenClaw без ручной настройки – коробочное решение. Есть встроенная модель GLM-5-Turbo, но можно использовать любую другую.

### Claude Code: Computer Use

Anthropic добавили новую фичу, которая позволяет агенту управлять компьютером как человек (смотреть на экран, двигать мышкой, кликать и взаимодействовать с любыми приложениями). Пока работает в тестовом режиме на MacOS.

### ClaudeCode: PowerUp

Добавили новую команду /powerup, которая показывает интерактивные уроки по работе с Claude Code – выглядит очень удобно.

### НОВЫЕ МОДЕЛИ

[DeepMind Gemma4](https://deepmind.google/models/gemma/gemma-4/). Open-source, доступны версии 26B и 31B, а также ультралёгкие E2B и E4B – специально edge-устройств. Уже стала топ-1 среди открытых моделей США. Старшие версии показывают сопоставимое качество с китайскими конкурентами в 20-30 раз больше (GLM-5, Kimi-K2.5-Thinking). 
Доступна в формате gguf для локального запуска.

**Alibaba Qwen3.6-Plus**. По API и на сайте. Новая флагманская модель, наследница серии Qwen 3.5. Почитать подробнее можно [здесь](https://t.me/ai_machinelearning_big_data/9805).

[Z.ai](https://z.ai) **GLM-5-Turbo & GLM-5V-Turbo**. По API. Модели, оптимизированные для агентных задач в OpenClaw. Первая работает только с текстом, вторая – с изображениями, видео и текстом. В ряде бенчмарков [превосходит даже Claude Opus 4.6](https://habr.com/ru/news/1018220/).

[H Company Holo3](https://huggingface.co/Hcompany/Holo3-35B-A3B). Open-source. Модели, предназначенные для управления графическими интерфейсами. Holo3-122B-A10B показала SOTA результат на бенчмарке OSWorld-Verified.

[LiquidAI LFM2.5-350M](https://huggingface.co/LiquidAI/LFM2.5-350M). Open-source. Агентная модель всего на 350 млн. параметров. Отлично подходит для edge-устройств: локальная обработка документов, легкие агентские воркфлоу.

**Google Veo 3.1 Lite**. По API. Более доступная модель генерации видео. Можно протестировать в [Google AI Studio](https://aistudio.google.com/prompts/new_video).

**Alibaba Wan2.7-Image**. По API. Модель генерации изображений нового поколения, ориентированная на сверхреалистичную генерацию лиц, точную передачу цветов и редактирование мелких деталей. Попробовать можно [тут](https://create.wan.video/generate/image/generate?model=wan2.7-pro).
